## 6. Hosting, data persistence, operations

- `render.yaml` (Blueprint): API `carbonroute-staging-api` (Free, Node 20, `NODE_ENV=production`,
  JWT secret generated by Render, data in the ephemeral `runtime-data/`), static site
  `carbonroute-staging-web` (`VITE_API_URL`). Auto-deploy is **off**: deploy with Render ›
  service › Manual Deploy › *Deploy latest commit* (API first, then the site).
- **Persistence: none on the free plan** — accounts, jobs and uploads are lost on every deploy,
  restart and after 15 minutes without traffic. The committed results (`results/published/`) and
  the zone catalogue are part of the code and always available. Research data never goes to staging.
- Logs: Render › service › Logs (no passwords, tokens or keys are logged; errors carry a reference id).
- Environment variable names: API `NODE_ENV`, `NODE_VERSION`, `JWT_SECRET`, `ADMIN_USERNAME`,
  `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `CORS_ORIGIN`, `TRUST_PROXY`, `CARBONROUTE_DB_FILE`, `STORAGE_TYPE`,
  `LOCAL_STORAGE_DIR`, `BENCHMARK_RESULTS_DIR`, `ML_RESULTS_DIR`, `EM_MAX_CALLS_PER_HOUR`,
  `EM_MAX_CALLS_PER_DAY` (optional `ELECTRICITY_MAPS_API_KEY`, absent on the free demo); site
  `VITE_API_URL`. Reference: [ENVIRONMENT.md](ENVIRONMENT.md).
- Re-verify after a deploy: `STAGING_ADMIN_PASSWORD=… node scripts/staging-check.mjs --api <API URL>
  --origin <site URL> --admin <admin>` (22 checks; skip `--verify-persisted` on the free plan).

## 8. Running locally

Node.js 20 (24 works), npm; optional Python 3.12.

```bash
cp .env.example .env            # fill in values (docs/ENVIRONMENT.md); never commit .env
cd backend && npm ci && npm run build && cd ..
cd frontend && npm ci && cd ..
cd backend && npm run dev       # API http://localhost:5000
cd frontend && npm run dev      # app http://localhost:5173
```

Accounts: `cd backend && NEW_USER_USERNAME=… NEW_USER_EMAIL=… NEW_USER_PASSWORD=… [NEW_USER_ROLE=admin] npm run user:create`.
Tests: `npm test` (backend, frontend); `py -3 -m unittest discover -s fastapi_service/tests`.
Rebuild the zone catalogue: `node scripts/zones/build-zone-catalogue.mjs`.
Research: see `results/published/README.md` (frozen snapshot → benchmark → ml → report).
