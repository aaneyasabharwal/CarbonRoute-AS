# Published results

Copies of replay benchmarks, forecast-error model evaluations and the research report, served
read-only by the staging backend (`BENCHMARK_RESULTS_DIR`, `ML_RESULTS_DIR` in `render.yaml`) so
the Results and Dashboard pages show real results. Earlier runs are kept, never overwritten.

| Run | Input | Headline (runtime CV 0.2, CarbonRoute vs Immediate, gCO2eq/kWh, 95 % cluster interval) | Status |
|---|---|---|---|
| `benchmark-2026-11-13T23-48-22-308Z` | 60 forecast snapshots, 170 realized values, 0.40 days | −7.21 [−17.39, +0.40]: no evidence of a difference | not conclusive |
| `benchmark-2026-11-14T14-30-03-628Z` | 115 forecast snapshots, frozen copy of the collection at 2026-11-14 14:40 UTC (dataset `0e9b960c6b21`), 1.00 day | −25.16 [−33.60, −16.86]: lower in this sample; simulated deadline violations 0.8 % (Greedy 20.0 %, Immediate 4.2 %) | **not statistically conclusive** (< 7 days) |
| `ml-2026-11-14T14-30-11-263Z` | 1,655 forecast/realized pairs (946 measured), 1 day | split 415 / 55 / 104 vs required 500 / 100 / 200 over 7 days | **insufficient-data: no model trained** |

`reports/research-report-2026-11-14T14-30-03-628Z.md` is the full report generated by
`npm run report` for the latest run (provenance, data quality per zone, forecast accuracy, policy
comparison, ML status, threats to validity).

Reproduce (in `backend/`, after `npm run build`), from a frozen copy of the collection:

```bash
npm run benchmark -- --data <snapshot dir> --out <dir> --seed 42 --workloads 20
npm run ml -- --data <snapshot dir> --out <dir>
npm run report -- --data <snapshot dir> --benchmarks <dir> --ml <dir>
```

A second benchmark run on the same snapshot and seed gave identical results (apart from the
timestamp and commit). The files contain aggregate statistics only (no user data, no keys, no raw
provider responses). Workloads are synthetic, emissions use an assumed energy model (0.125 kW per
vCPU, not measured) and deadline violations use simulated runtimes. The raw collection stays outside
the repository (`../CarbonRoute-AS-data/em-collection`, see docs/COLLECTOR.md).
